# Campus Maintenance Request System

A web-based campus facility maintenance reporting and management system for Universitas Klabat (UNKLAB).

## Project Overview

This application helps students, lecturers, and staff report damaged campus facilities. Admins verify reports and assign technicians, while technicians manage and update repair progress.

The system also integrates AI to analyze maintenance reports and recommend damage categories and urgency levels.

## Technology Stack

- React.js
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React
- JSON Server
- Gemini API

## User Roles

1. Student
2. Lecturer
3. Staff
4. Admin
5. Technician

## Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Open the project folder:

```bash
cd Campus-Maintenance-System
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
